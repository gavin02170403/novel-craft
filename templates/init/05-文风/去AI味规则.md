# 去AI味规则

> 针对AI辅助生成后的润色
> 核心原则：**不删除因果，只改写表达方式。**

---

## 四规则

### 规则1：标点限额与破折号降级

- 全文破折号（——）使用量削减 **80%以上**
- 除非表达"话语被突然粗暴打断"或"极度强烈的时空/心理转折"，否则一律用逗号或句号代替
- **禁止用破折号来切分连续的动作**
- 判断标准：删掉破折号后句子仍然通顺 → 破折号必须删

### 规则2：动作链条压缩

- **禁止**使用"第一、第二、第三""首先、其次、然后"或"换个角度"这种说明书式拆解
- 将机械的连续动作压缩为一句带有反馈感的流畅描写
- 保留动作带来的身体反馈（肌肉颤抖、重心偏移、触感），删除步骤编号
- 例：不要"第一根横档……第二根……第三根……"，改为"他手脚并用向上攀爬，风从侧面吹过来，吹动了衣领"

### 规则3：感官留白

- 同一描写段落中，**严禁**将视觉、听觉、嗅觉、味觉、触觉全部罗列
- 强制执行 **"一主一次"原则**：选取当前情境下最强烈的一个感官作为主写，最多辅以一个次要感官
- 剔除所有像化验报告一样精准但毫无情感波动的描述
- 例：不要"血珠是鲜红色的（视觉），含进嘴里，咸的（味觉），铁锈味（嗅觉）"，改为"他把手指含进嘴里，一股微咸的铁锈味在舌尖化开"

### 规则4：斩断空镜余音

- 章节或段落结尾，**严禁**出现"风吹过……""在光线里……""像……一样"这种刻意拉长镜头、强行制造意境的虚写
- 结尾要求干脆利落，用具体的动作、带悬念的对话或干冷的陈述直接收尾
- 判断标准：如果结尾可以拍成电影空镜头+配乐Fade-out → 必须改

## 改写公式

**感官输入 → 身体反应 → 心理活动 → 行动决定**

```
【感官输入】他闻到/听到/看到/摸到 _______
    ↓
【身体反应】他的 _______（部位）_______（反应）
    ↓
【心理活动】他意识到/想起/明白 _______
    ↓
【行动决定】他 _______（动作）
```

## 高风险区

| 风险等级 | 位置 | 处理建议 |
|----------|------|---------|
| **极高** | 每章前3段 | 承接上一章，只改写不删除 |
| **极高** | 每章后3段 | 铺垫下一章，只改写不删除 |
| **高** | 场景转换处 | 必须有感官余震过渡 |
| **中** | 新人物登场前3段 | 需要铺垫 |
| **低** | 纯动作描写中段 | 可正常处理 |

## 3秒检查法

润色完成后，读完上一章结尾和本章开头，问自己：

1. **动机**：他为什么突然做这个？
2. **线索**：上一章发现的东西，这一章还记得吗？
3. **情绪**：上一章那么强烈，这一章怎么延续？

判断标准：脑子里出现"为什么"三个字 → 需要补过渡。
