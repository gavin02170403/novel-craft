# 线索轨道表

> 动态调度层 · 每章写前看 · 每章写后更新
> 替代静态伏笔台账的「时间动力学」工具

---

## 使用规则

1. **写前**：扫一眼"下次该出现"列，判断本章该让哪条线升温
2. **写中**：不翻此表，按写作管线自由写
3. **写后**：更新"当前紧张度""上次出现""最近一次形态"，调整"下次该出现"

---

## 线索字段规范

| 字段 | 说明 | 示例 |
|------|------|------|
| 线索ID | 唯一标识，格式：{类型前缀}-{序号} | clue-001, char-002, item-003 |
| 线索名 | 简短描述 | "敲墙声/墙里的东西" |
| 类型 | clue（线索）/ char（人物关系）/ item（物品）/ place（地点）/ power（能力） | clue |
| 关联人物/势力 | 与这条线索相关的主要角色或势力 | "李太平、老张、南天门工地" |
| 当前形态 | 最近一次出现时的具体状态 | "墙内部是黑色骨粉，第八天会爆开" |
| 紧张度 | 1-10，见下方定义 | 8 |
| 上次出现 | 最近一次出现的章节号 | ch35 |
| 下次该出现 | 计划下次出现的章节号范围 | ch36-40 |
| 兑现目标 | 最终回收或引爆的章节 | "第一卷末" / ch90 |
| 读者可见度 | 隐藏/暗示/半明/明牌/已兑现 | 暗示 |
| 状态 | active（活跃）/ dormant（休眠）/ resolved（已回收）/ abandoned（废弃） | active |

---

## 读者可见度定义

| 级别 | 定义 | 示例 |
|------|------|------|
| **隐藏** | 读者完全不知道，只有作者/角色知道 | 反派真实身份 |
| **暗示** | 读者隐约感觉到"哪里不对"，但说不出 | 多次出现的不明声音 |
| **半明** | 读者知道有这回事，但不清楚全貌 | 名单上有名字，但不知道含义 |
| **明牌** | 读者和主角都知道，正在共同面对 | 墙要塌了，所有人都在修 |
| **已兑现** | 线索已回收，读者知道了真相 | 反派身份揭晓 |

> Agent 规划/写作时注意：`读者可见度` 控制信息披露节奏，防止提前剧透或把伏笔写太直。

---

## 紧张度定义

| 分值 | 状态 | 读者感受 |
|------|------|---------|
| 1-2 | 休眠 | 记得有这么个事，但不紧迫 |
| 3-4 | 存在 | 偶尔想起来，有隐约不安 |
| 5-6 | 升温 | actively 想知道答案 |
| 7-8 | 紧迫 | 每次出现心都提起来 |
| 9-10 | 临界 | 下一章就要爆了 |

## 写前快速扫描规则

写第X章时，只读取满足以下条件的行：

```
下次该出现 <= 第X章
AND 状态 = active
AND 紧张度 >= 3
```

按紧张度降序排列，优先处理紧张度高的线索。
