# 章纲模式

> 默认轻量细纲。用户明确要求工程化规划时切换严格节点。

---

## 模式切换

由 `state.json` 中的 `"outline_mode"` 控制：

```json
{"outline_mode": "lightweight"}  // 默认
{"outline_mode": "strict"}       // 高级模式
```

---

## 升级条件（何时从轻量切严格）

满足**任一**条件时，建议切换 `outline_mode` 为 `"strict"`：

| 条件 | 说明 |
|------|------|
| 多主角或群像 | 需要追踪多个POV角色的状态 |
| 悬疑/权谋/多线并行 | 线索交叉复杂，需要精确控制信息披露 |
| 单卷超过30章 | 轻量细纲难以维持长期一致性 |
| 伏笔线超过12条 active | 需要结构化节点防止遗漏 |
| 时间线跨地域、跨阵营、跨年代 | 需要严格的时间锚点管理 |
| 用户明确要求工程化大纲 | 用户主动选择 |

**降级条件**：从 strict 切回 lightweight 需要用户确认。Agent 不应自动降级。

---

## 轻量细纲（默认）

适合：快速写作、单主线、升级流、情绪驱动型

```markdown
# 第X章 · {章标题}

- 本章功能：{信息/压力/关系/转向/过渡}
- 开场承接：{从上一章的什么状态进入}
- 主要场景：{地点 + 时间}
- 必须覆盖：{需要完成的情节点，2-4条}
- 人物变化：{谁的状态/关系有变}
- 线索处理：
  - 推进：{线索A 紧张度 X→Y，具体变化}
  - 引入：{新线索B，预计N章后再次出现}
  - 交汇：{线索C × 线索D，交汇效果}
- 章末钩子：{读者最想知道什么，1-3个问题}
- 风险提醒：{本章禁区/易错点}
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 本章功能 | 是 | 单选：信息（揭示设定）、压力（增加阻力）、关系（人物变化）、转向（认知反转）、过渡（场景转换） |
| 开场承接 | 是 | 一句话描述上一章结束后的状态 |
| 主要场景 | 是 | 地点 + 大致时间（如"南天门工地 / 凌晨"） |
| 必须覆盖 | 是 | 2-4条，本章必须完成的情节点 |
| 人物变化 | 条件 | 若有人物状态/关系变化，列出；无变化写"无" |
| 线索处理 | 是 | 至少填写"推进"或"引入"之一 |
| 章末钩子 | 是 | 读者看完本章后最想知道的问题 |
| 风险提醒 | 否 | 本章易犯的错或绝对不能发生的事 |

## 严格节点（高级模式）

适合：复杂长篇、多线群像、悬疑推理、强情节工程

```markdown
# 第X章 · {章标题}

## 章节指令
- 目标：{本章核心任务}
- 时间锚点：{本章在整体时间线上的位置}
- 章节跨度：{本章内时间流逝}
- 倒计时状态：{如有倒计时，当前D-N}
- 章末未闭合问题：{读者最想知道的问题}

## 章节起点（CBN）
{主体 | 动作/变化 | 对象/结果}

## 推进节点（CPNs）
1. {主体 | 动作/变化 | 对象/结果}
2. {主体 | 动作/变化 | 对象/结果}
3. ...（2-4个）

## 章节终点（CEN）
{主体 | 动作/变化 | 对象/结果}

## 必须覆盖节点
- [ ] CBN
- [ ] CEN
- [ ] {核心CPN 1}
- [ ] {核心CPN 2}

## 本章禁区
1. {禁区}
2. ...（不超过5条）

## 线索处理
- 推进：{线索A 紧张度 X→Y}
- 引入：{新线索B}
- 交汇：{线索C × 线索D}
```

### 结构化节点规范

节点格式统一为：
```
主体 | 动作/变化 | 对象/结果
```

- `动作/变化` 可表示行动、判断、意识变化或状态转移
- `对象/结果` 可以是人、物、地点，也可以是结果状态

示例：
- `萧炎 | 抵达 | 迦南学院入口`
- `萧炎 | 展示 | 异火控制力`
- `药老 | 对萧炎产生 | 明确兴趣`
- `萧炎 | 意识到 | 学院考核远比预想更严苛`

结构规则：
- 每章固定 **1个 CBN**
- 每章 **2-4个 CPN**
- 每章固定 **1个 CEN**
- 相邻章节 `CEN → 下一章 CBN` 必须逻辑承接
- `CPNs` 必须按时间顺序排列

必须覆盖规则：
- 每章必须覆盖节点最多 **4个**
- 建议：`CBN + CEN + 1~2个核心CPN`

## 卷级规划（两种模式通用）

无论章纲用哪种模式，卷级规划都包含：

### 卷节拍表

```markdown
# 第V卷 · {卷名} 节拍表

## 卷摘要
{一段话描述本卷核心功能}

## 关键人物
- {人物}：{本卷中的角色定位}

## 节拍
| 节点 | 章节 | 内容 | 功能 |
|------|------|------|------|
| 开局 | chX | {内容} | 入局 |
| 第一次危机 | chY | {内容} | 压力递增 |
| 中段反转 | chZ | {内容} | 必须填写，无则写"无（理由）" |
| 第二次危机 | chA | {内容} | 压力递增 |
| 第三次危机 | chB | {内容} | 压力递增 |
| 卷末高潮 | chC | {内容} | 卷末释放 |
| 卷末钩子 | chD | {内容} | 通向下卷 |

## 危机链
1. {危机1} → 递增方式：{...}
2. {危机2} → 递增方式：{...}
3. {危机3} → 递增方式：{...}

## 新投线索
| 线索 | 投下章节 | 预计兑现 | 初始紧张度 |
|------|---------|---------|-----------|
| {线索A} | chX | chY | 3 |
```

### 卷时间线

```markdown
# 第V卷 · {卷名} 时间线

## 时间体系
{整体时间单位：天/月/年}

## 本卷跨度
{从 时间A 到 时间B}

## 倒计时事件（如有）
| 事件 | 起始时间 | 截止时间 | 当前D-N |
|------|---------|---------|---------|
| {事件A} | 第X天 | 第Y天 | D-10 |

## 章节时间分布
| 章节 | 时间点 | 跨度 | 与上章时间差 |
|------|--------|------|-------------|
| chX | 第3天 凌晨 | 2小时 | +6小时 |
| chY | 第3天 上午 | 4小时 | +2小时 |
```

---

## 模式选择指南

| 场景 | 推荐模式 | 理由 |
|------|---------|------|
| 单主角升级流 | lightweight | 节奏快，不需要严格节点约束 |
| 多线群像 | strict | 需要追踪多条线索的CBN/CEN衔接 |
| 悬疑推理 | strict | 线索交叉需要精确控制 |
| 日常/感情向 | lightweight | 重情绪轻情节，节点约束会束缚 |
| 用户要求快速推进 | lightweight | 减少规划负担 |
| 用户要求工程化管理 | strict | 提供完整的结构控制 |
